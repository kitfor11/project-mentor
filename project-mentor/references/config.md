# 教学配置

> 这里是可选的默认配置。多数时候你可以在对话里直接说明（如「用初级强度教我」），无需改文件。

## 教学强度（teaching_level）

当前默认档：**中级（intermediate）**

想换默认档时，把 `x` 移到你想用的那一档（每次只保留一个 `x`）：

- [ ] 初级（beginner）：几乎每个重要点都讲（篇幅 6~12 行），交办更多、更小的子任务，骨架给得更全。
- [x] 中级（intermediate）：只讲关键点（3~8 行），交办有思考含量的环节。
- [ ] 高级（advanced）：只讲架构决策与易错点，仅交办最关键、最难的一两处。
