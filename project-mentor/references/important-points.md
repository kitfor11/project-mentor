# 内置关键字段（重要点目录）

本文件是「重要点」的内置判断依据。智能体在项目中遇到下列类别的操作/概念时，应当讲解；其中标注 **建议交办** 的，优先交给用户亲手做。

> 扩充方法：直接在对应类别下增补子项，或新增一个类别。智能体会按本目录匹配「重要点」。

## 1. 项目结构与组织
- 目录结构设计、模块划分、分层（MVC / 三层 / 领域分层等）
- 依赖管理（package.json / go.mod / requirements.txt 等）
- 入口文件与启动流程
- 说明：多为「我来讲、我来做」，脚手架偏机械。

## 2. 数据模型与持久化
- 数据库表/集合结构设计、字段类型、主外键、索引
- ORM 模型定义、迁移（migration）
- 缓存设计
- 说明：**建议交办** —— 有思考含量，适合用户亲手设计。

## 3. 接口 / API 设计
- RESTful 路由设计、请求/响应格式、参数校验
- GraphQL schema、RPC 定义
- 说明：**建议交办** —— 用户设计接口、你评审。

## 4. 认证与授权
- 登录/注册、密码哈希、Session / JWT / OAuth
- 权限控制、中间件/拦截器
- 说明：**建议交办**，安全细节要重点讲。

## 5. 状态管理与数据流
- 前端全局状态（Redux / Pinia / Zustand 等）
- 组件间通信、单向数据流
- 说明：**建议交办**（若命中用户技术栈则必须交办）。

## 6. 错误处理
- 异常捕获、错误码、统一错误响应、日志
- 说明：可讲可交办，看复杂度。

## 7. 配置与环境
- 环境变量、配置文件、多环境（dev/test/prod）、密钥管理
- 说明：多为我来讲、我来做。

## 8. 构建与部署
- 构建脚本、CI/CD、容器化、部署流程
- 说明：多为我来讲、我来做。

## 9. 测试
- 单元测试、集成测试、测试框架、断言
- 说明：**建议交办** —— 写测试是很好的练习。

## 10. 性能与安全
- 查询优化、索引、缓存策略、懒加载
- 常见安全漏洞（SQL 注入、XSS、CSRF）与防护
- 说明：讲解为主，重要安全点要强调。

## 11. 核心业务逻辑与算法
- 业务规则实现、关键算法、状态机、事务
- 说明：**强烈建议交办** —— 这是最有学习价值的部分。

## 12. 抽象与复用
- 公共组件/工具函数抽取、设计模式、接口抽象
- 说明：可讲可交办。
